# Full Stack Web Development Lab 01
## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Git
- GitHub
## Lab Objectives
This lab demonstrates the development of a responsive web page using HTML5, CSS3 and
Bootstrap.
The lab also demonstrates Git repository creation, commits and GitHub repository
management.
## Features
- HTML5 semantic structure
- Responsive navigation bar
- Bootstrap grid
- Bootstrap cards
- Bootstrap buttons
- Custom CSS styling
- Responsive design
- Git repository
- GitHub repository
